# ContbusRedesign

A private-ready bus booking web app prototype built with React and Vite.

## Features

- Route search with origin, destination, dates, passenger count, and trip type
- Featured city routes and live departure-style trip cards
- Multi-step booking flow: select trip, choose seats, passenger details, payment, confirmation
- Ticket wallet with status, QR-style ticket visuals, and support actions
- Account panel for rewards, saved payment methods, alerts, and preferences
- Live operations dashboard for fleet status, delays, occupancy, refunds, and boarding
- Responsive layout for desktop and mobile

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
