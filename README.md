# Contbus Redesign

Polish-first Contbus website redesign prototype built with React and Vite.

## Features

- Polish, English, and Ukrainian language switcher
- Real Contbus route framing: Lublin, Warszawa Marriott, Lotnisko Chopina, Lotnisko Modlin
- Fare cards based on the public Contbus ticket price list
- Redesigned clickable ticket system prototype with route search, departures, passenger details, mock payment, confirmation, and ticket recovery
- Passenger-first stop guide and ticket actions
- Fallback link to the existing `bilety.contbus.pl` portal for comparison during the pitch
- Responsive pitch-ready layout for desktop and mobile

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
